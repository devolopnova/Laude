Recortar y pegar para niños a partir de 5 años

Las edades son orientativas. Cada niño puede disfrutar de una actividad de forma diferente y algunas propuestas pueden requerir más o menos ayuda según sus características y la dificultad de cada actividad. Todas las actividades deben realizarse siempre bajo la supervisión de un adulto responsable, utilizando materiales adecuados para la edad y siguiendo las indicaciones de seguridad correspondientes.

Ideas de recortar y pegar

Collage de un animal
A partir de 5 años 20–25 minutos Fácil

Materiales

  • Cartulina.
  • Papeles de diferentes colores.
  • Pegamento infantil adecuado para la edad.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Elige un animal para crear.
  2. Dibuja o prepara las formas principales sobre papeles de diferentes colores.
  3. Recorta las piezas.
  4. Colócalas sobre la cartulina hasta encontrar una composición que te guste.
  5. Pega las piezas y añade los últimos detalles.

Una idea para hacerlo diferente

Podéis crear varios animales y montar una pequeña escena de selva, granja o bosque.

Supervisión

El adulto debe supervisar siempre el uso de las tijeras y ayudar cuando sea necesario. Utilizar materiales adecuados para la edad y realizar siempre la actividad bajo la supervisión de un adulto responsable.

Árbol de las estaciones
A partir de 5 años 25 minutos Fácil

Materiales

  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  5. Pega las hojas cuando estés satisfecho con la composición.

Fondo marino de papel
A partir de 5 años 25–30 minutos Fácil

Materiales

  • Cartulina azul.
  • Papeles de diferentes colores.
  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Utiliza la cartulina azul como fondo.
  2. Recorta peces, algas, burbujas y otras formas.
  3. Coloca todas las piezas sobre la cartulina.
  4. Prueba diferentes composiciones.
  5. Pega las piezas para crear el fondo marino.

Una idea para hacerlo diferente

Podéis inventar un animal marino que no exista y añadirlo al fondo.

Supervisión

El adulto debe supervisar siempre el uso de las tijeras y comprobar que todos los materiales sean adecuados para la edad. Realizar siempre la actividad bajo la supervisión de un adulto responsable.

Una casa hecha con formas
A partir de 5 años 20–25 minutos Fácil

Materiales

  • Cartulina.
  • Papeles de diferentes colores.
  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Recorta un cuadrado o rectángulo grande para la casa.
  2. Prepara un triángulo para el tejado.
  3. Añade ventanas, puerta y otros elementos.
  4. Coloca todas las piezas sobre la cartulina.
  5. Pega las piezas y añade los detalles finales.

Una idea para hacerlo diferente

Podéis crear una casa diferente a la habitual: una casa en un árbol, un castillo o una casa espacial.

Supervisión

Arcoíris de papel
A partir de 5 años 20 minutos Fácil

Materiales

  • Cartulina.
  • Papeles de diferentes colores.
  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.

Cómo hacerlo

  5. Añade nubes utilizando papel blanco.

Oruga de círculos de papel
A partir de 5 años 20 minutos Fácil

Materiales

  • Cartulina.
  • Papeles de diferentes colores.
  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Prepara varios círculos de papel.
  2. Colócalos uno junto a otro formando el cuerpo de la oruga.

  5. Añade ojos, antenas y otros detalles.

Personaje de formas recortadas
A partir de 5 años 25–30 minutos Fácil

Materiales

  • Cartulina.
  • Papeles de diferentes colores.
  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Recorta círculos, cuadrados, triángulos y otras formas.
  2. Combina las formas para crear un personaje.
  3. Prueba diferentes posiciones antes de pegarlas.
  4. Pega las piezas sobre la cartulina.
  5. Añade ojos, boca, pelo y otros detalles.

Una idea para hacerlo diferente

Podéis crear una familia de personajes utilizando diferentes formas, tamaños y colores.

Supervisión

El adulto debe supervisar siempre el uso de las tijeras y ayudar cuando sea necesario. Utilizar materiales adecuados para la edad y realizar siempre la actividad bajo la supervisión de un adulto responsable.
