Decorar y montar para niños a partir de 3 años

Las edades son orientativas. Cada niño puede disfrutar de una actividad de forma diferente y algunas propuestas pueden requerir más o menos ayuda según sus características y la dificultad de cada actividad. Todas las actividades deben realizarse siempre bajo la supervisión de un adulto responsable, utilizando materiales adecuados para la edad y siguiendo las indicaciones de seguridad correspondientes.

Ideas de decorar y montar

Yogur decorado con fruta
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Yogur natural.
  • Fruta blanda adecuada para la edad.
  • Un bol o vaso.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara previamente la fruta.
  2. Coloca el yogur en el recipiente.
  3. Elige qué fruta quieres utilizar.
  4. Coloca los trozos sobre el yogur.
  5. Decide cómo quieres distribuirlos.

Una idea para hacerlo diferente

Intentad hacer una decoración formando un círculo, una línea o una figura sencilla.

Supervisión

El adulto prepara previamente la fruta en un tamaño y textura adecuados para la edad.

Tostada con formas
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Pan blando.
  • Queso crema u otro ingrediente adecuado para untar.
  • Fruta blanda previamente preparada.

Cómo hacerlo

  1. El adulto prepara el pan.
  2. Extiende una pequeña cantidad del ingrediente elegido.
  3. Elige los alimentos que quieres colocar encima.
  4. Colócalos formando una figura.
  5. Observa cómo cambia la tostada al añadir cada elemento.

Una idea para hacerlo diferente

Intentad crear una cara utilizando únicamente los ingredientes disponibles.

Supervisión

El adulto realiza cualquier corte y comprueba que los ingredientes sean adecuados para el niño.

Vasito de colores
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Yogur natural.
  • Dos o tres frutas blandas de diferentes colores.
  • Un vaso o recipiente transparente.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara previamente la fruta.
  2. Coloca una primera capa de yogur.
  3. Añade una fruta.
  4. Añade otra capa de yogur.
  5. Continúa alternando los ingredientes.

Una idea para hacerlo diferente

Intentad crear dos vasitos utilizando un orden de colores diferente.

Supervisión

La fruta debe estar preparada en un tamaño y textura adecuados para la edad.

Galletas decoradas
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Galletas adecuadas para la edad.
  • Yogur espeso o una crema apta para el niño.
  • Fruta blanda previamente preparada.

Cómo hacerlo

  1. Coloca una galleta sobre un plato.
  2. Extiende una pequeña cantidad de yogur o crema.
  3. Elige los ingredientes para decorarla.
  4. Colócalos sobre la superficie.
  5. Crea una decoración sencilla.

Una idea para hacerlo diferente

Intentad hacer dos galletas con diseños diferentes.

Supervisión

El adulto debe comprobar que las galletas y los ingredientes sean apropiados para la edad y realizar cualquier preparación necesaria.

Mini bocadillo divertido
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Pan blando.
  • Queso u otro relleno adecuado.
  • Ingredientes blandos previamente preparados.

Cómo hacerlo

  1. El adulto prepara el pan y los ingredientes.
  2. Coloca el relleno sobre una de las piezas.
  3. Decide qué ingredientes quieres añadir.
  4. Colócalos en el interior.
  5. Cierra el bocadillo y presiónalo suavemente.

Una idea para hacerlo diferente

Intentad hacer dos bocadillos con combinaciones diferentes.

Supervisión

El adulto realiza cualquier corte y adapta los ingredientes a la edad del niño.

Ordena la fruta
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Dos o tres tipos de fruta blanda adecuada para la edad.
  • Un plato o recipiente.

Cómo hacerlo

  1. El adulto prepara previamente la fruta.
  2. Coloca todos los trozos sobre la mesa.
  3. Elige un orden.
  4. Coloca la fruta siguiendo ese patrón.
  5. Observa el resultado final.

Una idea para hacerlo diferente

Haz un patrón sencillo, por ejemplo:
pera → plátano → pera → plátano
y después inventa otro.

Supervisión

El adulto prepara previamente la fruta y comprueba que tenga un tamaño y textura adecuados.

Crea un dibujo con alimentos
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Fruta blanda.
  • Yogur.
  • Un plato.

Cómo hacerlo

  1. El adulto prepara los ingredientes.
  2. Elige qué quieres representar.
  3. Utiliza la fruta para crear las diferentes partes.
  4. Añade yogur donde quieras.
  5. Observa tu creación antes de comerla.

Una idea para hacerlo diferente

Intentad crear primero un animal y después una cara utilizando los mismos ingredientes.

Supervisión

El adulto prepara previamente todos los alimentos.

Mi merienda decorada
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Una preparación sencilla ya lista.
  • Fruta u otros ingredientes blandos adecuados para decorar.
  • Un plato.

Cómo hacerlo

  1. Coloca la preparación sobre el plato.
  2. Elige los ingredientes que quieres utilizar.
  3. Decide dónde colocar cada uno.
  4. Decora la preparación a tu manera.
  5. Explica qué has creado.

Una idea para hacerlo diferente

Haz primero un diseño y después intenta crear otro completamente diferente utilizando los mismos ingredientes.

Supervisión

El adulto prepara todos los alimentos y comprueba que sean adecuados para la edad.
