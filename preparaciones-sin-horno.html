Preparaciones sin horno para niños a partir de 3 años

A partir de 3 años

Las edades son orientativas. Cada niño puede disfrutar de una actividad de forma diferente y algunas propuestas pueden requerir más o menos ayuda según sus características y la dificultad de cada actividad. Todas las actividades deben realizarse siempre bajo la supervisión de un adulto responsable, utilizando materiales adecuados para la edad y siguiendo las indicaciones de seguridad correspondientes.

Ideas de preparaciones sin horno

Barquitos de pepino
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Pepino.
  • Queso crema u otro ingrediente blando adecuado.
  • Un ingrediente blando para decorar.

Cómo hacerlo

  1. El adulto lava y corta previamente el pepino en piezas adecuadas.
  2. Coloca las piezas sobre un plato.
  3. Extiende una pequeña cantidad de queso crema.
  4. Añade el ingrediente elegido.
  5. Decora cada pieza para convertirla en un pequeño "barquito".

Una idea para hacerlo diferente

Intentad crear varios barcos con decoraciones diferentes.

Supervisión

El adulto realiza todos los cortes y comprueba que los alimentos tengan un tamaño y textura adecuados.

Tostadas de aguacate
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Pan blando.
  • Aguacate maduro.
  • Un recipiente.
  • Un utensilio adecuado para aplastar.

Cómo hacerlo

  1. El adulto prepara previamente el pan y el aguacate.
  2. Coloca el aguacate en un recipiente.
  3. Aplástalo hasta conseguir una textura cremosa.
  4. Extiéndelo sobre el pan.
  5. Decora la tostada con algún ingrediente blando adecuado.

Una idea para hacerlo diferente

Prepara una tostada completamente lisa y otra dejando pequeños trozos de aguacate.

Supervisión

El adulto realiza cualquier corte y prepara previamente los alimentos.

Bolitas de queso fresco
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Queso fresco adecuado para la edad.
  • Un ingrediente blando para añadir por fuera.
  • Un plato.

Cómo hacerlo

  1. El adulto prepara el queso en porciones adecuadas.
  2. Coge una porción con las manos limpias.
  3. Dale forma redondeada suavemente.
  4. Colócala sobre el plato.
  5. Añade por encima un ingrediente blando adecuado.

Una idea para hacerlo diferente

Intentad hacer bolitas de diferentes tamaños.

Supervisión

El adulto controla el tamaño de las porciones y comprueba que la textura sea adecuada para la edad.

Rollitos de tortilla fría
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Tortilla de trigo ya preparada y adecuada para la edad.
  • Queso crema u otro relleno blando.
  • Ingredientes blandos previamente preparados.

Cómo hacerlo

  1. El adulto coloca la tortilla sobre una superficie limpia.
  2. Extiende el relleno.
  3. El niño coloca los ingredientes elegidos.
  4. Enrolla la tortilla con ayuda del adulto.
  5. El adulto corta el rollito en las porciones adecuadas.

Una idea para hacerlo diferente

Preparad dos rollitos con rellenos diferentes y comparadlos.

Supervisión

El adulto realiza el corte y supervisa todo el proceso.

Montaditos fríos
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Pan blando.
  • Queso u otro ingrediente adecuado.
  • Ingredientes blandos previamente preparados.

Cómo hacerlo

  1. El adulto prepara todos los ingredientes.
  2. Coloca una pieza de pan sobre el plato.
  3. Añade la base elegida.
  4. Coloca encima otro ingrediente.
  5. Termina el montadito con un último elemento.

Una idea para hacerlo diferente

Intentad preparar tres montaditos siguiendo tres combinaciones diferentes.

Supervisión

El adulto realiza cualquier corte y adapta todos los ingredientes a la edad.

Ensaladilla sencilla
A partir de 3 años 20 minutos Fácil

Ingredientes

  • Patata previamente cocida y enfriada.
  • Zanahoria previamente cocida y enfriada.
  • Otros ingredientes blandos adecuados.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara y corta previamente los ingredientes.
  2. Colócalos en un bol.
  3. Añade los ingredientes uno a uno.
  4. Mezcla suavemente con la cuchara.
  5. Observa cómo se transforma la preparación.

Una idea para hacerlo diferente

Prepara primero una pequeña cantidad y después otra cambiando uno de los ingredientes.

Supervisión

Toda la cocción y el corte los realiza el adulto. Comprobar previamente posibles alergias e intolerancias.

Canapés sencillos
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Pan blando.
  • Queso crema u otra base adecuada.
  • Ingredientes blandos previamente preparados.

Cómo hacerlo

  1. El adulto prepara las piezas de pan.
  2. Extiende la base elegida.
  3. El niño selecciona un ingrediente.
  4. Lo coloca sobre el pan.
  5. Repite el proceso creando diferentes combinaciones.

Una idea para hacerlo diferente

Preparad tres canapés y utilizad una combinación diferente en cada uno.

Supervisión

El adulto prepara previamente todos los ingredientes y realiza cualquier corte necesario.

Huevos rellenos sencillos
A partir de 3 años 20 minutos Fácil

Ingredientes

  • Huevos previamente cocidos.
  • Un relleno blando adecuado.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. El adulto cuece y enfría previamente los huevos.
  2. El adulto los pela y corta.
  3. Retira cuidadosamente la parte que vaya a utilizarse para el relleno.
  4. El niño ayuda a mezclar el relleno con una cuchara.
  5. Con ayuda del adulto, coloca el relleno en las mitades preparadas.

Una idea para hacerlo diferente

Preparad dos rellenos diferentes y comparad el resultado.

Supervisión

La cocción, el pelado y todos los cortes los realiza el adulto. Comprobar posibles alergias e intolerancias.
