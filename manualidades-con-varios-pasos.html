Manualidades con varios pasos para niños a partir de 5 años

Las edades son orientativas. Cada niño puede disfrutar de una actividad de forma diferente y algunas propuestas pueden requerir más o menos ayuda según sus características y la dificultad de cada actividad. Todas las actividades deben realizarse siempre bajo la supervisión de un adulto responsable, utilizando materiales adecuados para la edad y siguiendo las indicaciones de seguridad correspondientes.

Ideas de manualidades con varios pasos

Casita de pájaros decorativa
A partir de 5 años 40–50 minutos Media

Materiales

  • Cartón.
  • Papel de colores.
  • Pegamento.
  • Ceras o rotuladores.
  • Tijeras infantiles adecuadas para la edad.

Cómo hacerlo

  1. Prepara las piezas de cartón que formarán las paredes y el tejado.
  2. Une las piezas para construir la casita.
  3. Decora las paredes con papel y dibujos.
  4. Añade el tejado y otros detalles.
  5. Termina decorando la entrada y el exterior.

Una idea para hacerlo diferente

Podéis crear una pequeña familia de pájaros de papel para colocar alrededor de la casita.

Supervisión

El adulto debe realizar o supervisar los cortes y ayudar con el montaje cuando sea necesario. Realizar siempre la actividad bajo la supervisión de un adulto responsable.

Rueda de feria de papel
A partir de 5 años 35–45 minutos Media

Materiales

  • Cartulina.
  • Papel de colores.
  • Pajitas de papel o palitos adecuados para la edad.
  • Pegamento.
  • Tijeras infantiles.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Prepara un círculo grande de cartulina.
  2. Divide el círculo en varias partes y decóralas.
  3. Prepara pequeñas cabinas de papel.
  4. Coloca las cabinas alrededor de la rueda.
  5. Monta la rueda sobre una base de cartón.

Una idea para hacerlo diferente

Podéis crear alrededor una pequeña feria con puestos, banderines y otros elementos de papel.

Supervisión

El adulto debe supervisar los cortes y el montaje de la estructura. Comprobar que todos los materiales sean adecuados para la edad y realizar siempre la actividad bajo la supervisión de un adulto responsable.

Árbol de las cuatro estaciones
A partir de 5 años 35–45 minutos Media

Materiales

  • Cartulina.
  • Papel de diferentes colores.
  • Pegamento.
  • Tijeras infantiles adecuadas para la edad.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Dibuja un árbol grande sobre una cartulina.
  2. Divide la composición en cuatro zonas.
  3. Prepara hojas, flores y otros elementos de diferentes colores.
  4. Coloca los elementos correspondientes a cada estación.
  5. Pega todo y añade detalles.

Una idea para hacerlo diferente

Podéis utilizar diferentes texturas de papel para representar cada estación.

Supervisión

El adulto debe supervisar el uso de las tijeras y ayudar con los recortes cuando sea necesario. Realizar siempre la actividad bajo la supervisión de un adulto responsable.

Teatro de sombras de cartón
A partir de 5 años 40–50 minutos Media

Materiales

  • Una caja de cartón.
  • Papel vegetal o papel fino adecuado.
  • Cartulina negra.
  • Palitos de madera adecuados para la edad.
  • Pegamento.
  • Tijeras infantiles.

Cómo hacerlo

  1. Prepara una abertura en la caja.
  2. Coloca el papel fino sobre la abertura.
  3. Prepara personajes sencillos con cartulina.
  4. Une los personajes a los palitos.
  5. Coloca una luz detrás de la pantalla y representa una pequeña historia.

Una idea para hacerlo diferente

Podéis crear tres o cuatro personajes y preparar una historia corta para representarla delante de la familia.

Supervisión

El adulto debe realizar los cortes de la caja y supervisar el uso de la luz y los palitos. Realizar siempre la actividad bajo la supervisión de un adulto responsable.

Móvil de mariposas
A partir de 5 años 30–40 minutos Media

Materiales

  • Cartulina.
  • Papel de colores.
  • Hilo.
  • Una rama limpia o una pieza ligera de cartón.
  • Pegamento.
  • Tijeras infantiles.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Dibuja varias mariposas sobre cartulina.
  2. Recórtalas y decóralas.
  3. Prepara varios trozos de hilo.
  4. Une las mariposas a los hilos.
  5. Ata los hilos a la rama o estructura para formar el móvil.

Una idea para hacerlo diferente

Podéis combinar mariposas de diferentes tamaños y añadir flores o pequeñas hojas.

Supervisión

El adulto debe supervisar los recortes y el montaje del móvil y colocarlo fuera del alcance del niño cuando esté terminado. Realizar siempre la actividad bajo la supervisión de un adulto responsable.

Volcán de papel y cartón
A partir de 5 años 40–50 minutos Media

Materiales

  • Cartón.
  • Papel de periódico o papel usado.
  • Pegamento.
  • Pintura lavable.
  • Un recipiente pequeño.
  • Ceras o rotuladores.

Cómo hacerlo

  1. Coloca el recipiente sobre una base de cartón.
  2. Construye alrededor una estructura con papel y cartón.
  3. Deja secar la estructura.
  4. Pinta y decora el volcán.
  5. Coloca el recipiente en el interior para utilizarlo posteriormente.

Una idea para hacerlo diferente

Podéis crear alrededor del volcán un pequeño paisaje con árboles, rocas y otros elementos de papel.

Supervisión

El adulto debe encargarse de preparar la estructura y supervisar cualquier actividad posterior que se realice con el volcán. Utilizar únicamente materiales adecuados para la edad y realizar siempre la actividad bajo la supervisión de un adulto responsable.

Barco de cartón
A partir de 5 años 40–50 minutos Media

Materiales

  • Cartón.
  • Papel de colores.
  • Pegamento.
  • Ceras o rotuladores.
  • Tijeras infantiles adecuadas para la edad.

Cómo hacerlo

  1. Prepara una base de cartón para el barco.
  2. Añade los laterales y la parte superior.
  3. Prepara un mástil y una vela de papel.
  4. Une las diferentes piezas.
  5. Decora el barco con colores y otros detalles.

Una idea para hacerlo diferente

Podéis crear varios barcos y preparar un pequeño océano de papel para colocarlos juntos.

Supervisión

El adulto debe realizar o supervisar los cortes y ayudar con el montaje de las piezas. Realizar siempre la actividad bajo la supervisión de un adulto responsable.

Mini circo de cartón
A partir de 5 años 45–60 minutos Media

Materiales

  • Cartón.
  • Papel de colores.
  • Pegamento.
  • Ceras o rotuladores.
  • Tijeras infantiles adecuadas para la edad.

Cómo hacerlo

  1. Prepara una base de cartón.
  2. Construye la carpa utilizando cartón y papel.
  3. Decora la estructura con diferentes colores.
  4. Añade pequeñas figuras y elementos de papel.
  5. Organiza todos los elementos sobre la base para crear el circo.

Una idea para hacerlo diferente

Podéis inventar los personajes y preparar una pequeña historia que tenga lugar dentro del circo.

Supervisión

El adulto debe realizar o supervisar los cortes y ayudar con el montaje de la estructura. Comprobar que todos los elementos sean estables y seguros y realizar siempre la actividad bajo la supervisión de un adulto responsable.
