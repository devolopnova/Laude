Mezclar ingredientes para niños a partir de 3 años

Las edades son orientativas. Cada niño puede disfrutar de una actividad de forma diferente y algunas propuestas pueden requerir más o menos ayuda según sus características y la dificultad de cada actividad. Todas las actividades deben realizarse siempre bajo la supervisión de un adulto responsable, utilizando materiales adecuados para la edad y siguiendo las indicaciones de seguridad correspondientes.

Ideas de mezclar ingredientes

Mezcla de yogur y plátano
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Yogur natural.
  • Plátano maduro.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara previamente el plátano.
  2. Coloca el yogur en el bol.
  3. Añade los trozos de plátano.
  4. Aplasta algunos trozos con la cuchara.
  5. Mezcla hasta conseguir la textura que quieras.

Una idea para hacerlo diferente

Haz una mezcla con algunos trozos enteros y otra completamente homogénea.

Supervisión

El adulto prepara previamente el plátano y comprueba que la textura sea adecuada.

Yogur con avena
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Yogur natural.
  • Copos de avena finos adecuados para la edad.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. Coloca el yogur en el bol.
  2. Añade una pequeña cantidad de avena.
  3. Mezcla lentamente.
  4. Observa cómo cambia la textura.
  5. Añade un poco más de avena si quieres modificarla.

Una idea para hacerlo diferente

Prepara una mezcla más líquida y otra más espesa y compáralas.

Supervisión

Comprobar previamente posibles alergias o intolerancias.

Mezcla de pera y yogur
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Pera madura.
  • Yogur natural.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara previamente la pera.
  2. Coloca el yogur en el recipiente.
  3. Añade la pera.
  4. Mezcla suavemente.
  5. Aplasta algunos trozos y vuelve a mezclar.

Una idea para hacerlo diferente

Haz una mezcla con trozos visibles y otra más homogénea.

Supervisión

El adulto prepara la fruta en un tamaño y textura adecuados.

Crema de fruta aplastada
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Fruta madura y blanda adecuada para la edad.
  • Un bol.
  • Un utensilio adecuado para aplastar.

Cómo hacerlo

  1. El adulto prepara previamente la fruta.
  2. Colócala en el bol.
  3. Aplástala poco a poco.
  4. Observa cómo cambia su textura.
  5. Decide cuándo está suficientemente mezclada.

Una idea para hacerlo diferente

Intentad conseguir una textura con algunos trozos y otra más uniforme.

Supervisión

La fruta debe estar previamente preparada y ser adecuada para la edad.

Mezcla de yogur de dos colores
A partir de 3 años 10 minutos Fácil

Ingredientes

  • Yogur natural.
  • Dos frutas blandas de colores diferentes.
  • Dos recipientes.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara las frutas.
  2. Coloca cada fruta con una parte del yogur en recipientes separados.
  3. Mezcla cada uno.
  4. Observa los dos colores.
  5. Junta las dos mezclas y remueve suavemente.

Una idea para hacerlo diferente

Antes de juntarlas, intenta adivinar qué color aparecerá al mezclarlas.

Supervisión

Utilizar únicamente alimentos adecuados para la edad.

Mezcla cremosa de tres ingredientes
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Yogur natural.
  • Plátano maduro.
  • Avena fina adecuada para la edad.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. Coloca el yogur en el bol.
  2. Añade el plátano preparado por el adulto.
  3. Incorpora una pequeña cantidad de avena.
  4. Mezcla lentamente.
  5. Observa cómo cambia la textura con cada ingrediente.

Una idea para hacerlo diferente

Añade los ingredientes en un orden diferente y observa si la mezcla cambia.

Supervisión

Comprobar previamente alergias e intolerancias.

Combina tres ingredientes
A partir de 3 años 10–15 minutos Fácil

Ingredientes

  • Tres ingredientes blandos adecuados para la edad.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. El adulto prepara previamente todos los ingredientes.
  2. Añade el primero al bol.
  3. Incorpora el segundo.
  4. Añade el tercero.
  5. Mezcla y observa el resultado.

Una idea para hacerlo diferente

Haz una primera mezcla con dos ingredientes y después incorpora el tercero. Compara los cambios.

Supervisión

El adulto selecciona y prepara los ingredientes adecuados para la edad.

Crea tu propia mezcla
A partir de 3 años 15 minutos Fácil

Ingredientes

  • Dos o tres ingredientes blandos adecuados para la edad.
  • Un bol.
  • Una cuchara.

Cómo hacerlo

  1. Elige entre los ingredientes preparados por el adulto.
  2. Decide cuáles quieres combinar.
  3. Añádelos al recipiente.
  4. Mezcla lentamente.
  5. Observa el resultado y explica qué ha cambiado.

Una idea para hacerlo diferente

Haz una segunda mezcla cambiando solamente uno de los ingredientes.

Supervisión

El adulto selecciona previamente los ingredientes y supervisa toda la actividad.
